# 静态二进制构建公共注释标准

本文件集中维护多个 `build_<软件名>.sh` 共用的固定中文注释。仅在实际存在相同操作时逐字复用，不为统一格式增添不必要的步骤。

| 用途 | 固定注释原文 |
| --- | --- |
| 严格模式 | `# 命令执行失败、变量未定义或管道失败时立即退出。` |
| 工作目录 | `# 仅清理当前软件的工作目录与输出目录。` |
| 编译过程 | `# 保留当前软件已经验证的专属编译参数与执行顺序。` |
| 产物复制 | `# 将静态主程序复制到 dist 目录。` |
| 产物与元数据 | `# 统一检查静态 ELF，并生成实际版本与 SHA-256。` |

软件专属规则保持在软件目录：`lshw` 保留分阶段 core/static 命令；`strace`、`tcpdump` 保留 Linux UAPI 处理；`tcpdump` 分别获取 libpcap 与自身版本；`tree` 保留官方 tarball 与 Git Tag 源码逐文件核对；`xclipglue` 保留官网源码版本、man page 和 Git HEAD 的对照。

版本从官方上游动态获取，`dist/version.txt` 只包含当前版本；`software_versions.json` 仍由共享 Action 更新。公共代码不得依赖参考仓库运行时资源。
