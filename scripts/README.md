# 仓库维护工具

这里存放供维护者显式调用的脚本。日常构建使用 `common/` 和 `.github/` 下的入口。

| 分类 | 用途 |
| --- | --- |
| [归档](./archive/README.md) | 预览并归档指定的静态二进制软件 |
| [提交](./commit/README.md) | 生成提交说明和实机验证记录，预览并撤回指定提交 |
| [Release](./release/README.md) | 按准确资产名维护 Release 附件 |
| [同步](./sync/README.md) | 快进拉取、推送已有提交或提交指定文件后推送 |

每个工具的同名说明记录用途、运行条件、用法和影响。执行前按 [仓库操作规范](../AGENTS.md) 核对本次操作范围和授权。

## 公开内容约定

示例使用通用参数或占位符。提交、归档说明和运行记录只写入可公开的技术事实与实际验证范围。认证使用调用者已配置的凭据。
