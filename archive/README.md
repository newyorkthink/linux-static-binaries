# 已归档的静态二进制软件

本目录保留退出正式构建的软件完整目录及其历史登记。`static-binaries.json` 保存归档前的构建参数，供核对和恢复使用。

归档前通过[归档说明](../scripts/archive/archive_static_binary.md)预览。归档后的目录退出手动构建、Push 构建和 Release 自动重建。已发布的附件和版本清单中的历史条目继续保留。

## 恢复

阅读归档目录内的 README 和原登记，再将完整目录移回仓库根目录。按软件 key 的字母顺序把原登记加回活动清单，并在正式构建工作流中恢复手动下拉选项、Push 路径和 Markdown 排除路径。同步移除归档清单和列表中的对应条目。完成检查后按仓库规则提交。
